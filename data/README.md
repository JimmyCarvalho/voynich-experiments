Run `bash scripts/fetch_data.sh` from the repository root. It downloads, into `experiments/`:

- ZL3b-n.txt and GC2a-n.txt (transliterations, voynich.nu, used with attribution)
- the bible-corpus XML files used as language controls, and latin_words.txt / vulgate.txt
- the Naibbe cipher repository (Michael A. Greshko, MIT licence with citation requirement)
- the public-domain scans PDF from the Internet Archive (56 MB), for the image experiments

Nothing from those sources is redistributed in this repository.
